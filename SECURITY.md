# Security Policy

## Reporting Security Vulnerabilities

We take security seriously. If you identify a security vulnerability, issue, or unintended exposure in this repository, please do **not** report it in a public GitHub issue.

Please report vulnerabilities privately using GitHub's **Private Vulnerability Reporting** feature on this repository, or contact the maintainers via email at:
- `andreyvinicius@furg.br`
- `contato.ginfo@furg.br`

### What to Include
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Affected scripts, modules, or dependencies.
- Potential impact and suggested mitigations.

Do not include active credentials, private API keys, or proprietary data in your report.
